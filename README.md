# 🎯 YouTube Ad Skipper 🚀

Tired of clicking "Skip Ad" every 2 minutes? Let this lil' buddy do it for you! 😎

---

## 🔧 What it does
- Automatically clicks **"Skip Ad"** the *second* it appears ⏱️
- Works on **skippable** video ads only (sorry, unskippable ones are YouTube’s evil genius plan 😈)
- No lag, no fuss — just smooth, uninterrupted videos 🎬

---

## 🛠️ How to Install
1. 📦 Clone or download this repo
2. 🔌 Open `chrome://extensions` in your browser
3. ✅ Enable **Developer mode** (top-right)
4. 📂 Click **"Load unpacked"** and select this folder
5. 🟢 Toggle the extension ON

Boom! You're all set. Go enjoy ad-free(ish) YouTube! 🍿

---

## ⚠️ Note
This isn’t an ad blocker — it just auto-clicks skip. So technically, the ad loads… but who cares? You won’t see it! 😉
